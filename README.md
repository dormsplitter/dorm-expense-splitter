# Dorm Expense Splitter (DormSplit) - Group 3

DormSplit is a full-stack web application designed to track, calculate, and split shared dormitory expenses among up to 13 students cleanly and efficiently.

## 🚀 Live Application Links
- **Live Frontend App:** https://dorm-expense-splitte-zroq.bolt.host
- **Live Backend API:** https://group3member.pythonanywhere.com

## 🛠 Tech Stack & Architecture

### Frontend
- **Framework:** React with TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Bolt.host

### Backend
- **Framework:** Python Flask (REST API)
- **Database:** SQLite
- **CORS:** Enabled for secure cross-origin requests
- **Primary Backend File:** `app.py`
- **Deployment:** PythonAnywhere
